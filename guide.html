GETTING STARTED / PRIMEROS PASOS

A clear first step
Un primer paso claro

1. Download and verify / Descargar y verificar

Use the official release page. Choose the installer for Windows 10/11 x64, or the portable executable. Compare its SHA-256 hash with SHA256SUMS.txt using Windows PowerShell: 

Get-FileHash -Algorithm SHA256 "SOPBuilder Setup 0.3.0.exe"

The executable is not Authenticode-signed and Windows may show SmartScreen. A checksum detects corruption or replacement against the published reference; it is not a publisher signature. Do not disable antivirus or download from unofficial mirrors.

Usa la descarga oficial y compara SHA-256. El ejecutable no está firmado comercialmente; la huella no sustituye una firma del editor. No desactives el antivirus.

2. Redeem and import / Canjear e importar

After an approved purchase, use the redemption URL in your AppSumo purchase instructions. Enter the code and purchase email, accept the terms and save the .soplicense file. In SOPBuilder choose “Import license”. Save the original file privately; the file contains your email. The same code and email recover the license if a download was interrupted. Initial redemption requires internet, then local features work offline.

Tras una compra aprobada, usa la URL de canje de las instrucciones de AppSumo, guarda el archivo e impórtalo en SOPBuilder. No publiques códigos ni archivos de licencia.

3. Create your first procedure / Crear el primer SOP

  1. Choose the interface language and workspace name in onboarding.
  2. Open Templates, choose a realistic example and adapt it to your business.
  3. Review the purpose, owner, materials, expected outcomes and review date.
  4. Add actions, checklists, decisions or evidence steps; check each criterion.
  5. Approve and publish when the procedure passes validation.

Selecciona idioma y espacio, adapta una plantilla, revisa los datos generales, añade pasos y publica cuando pase la validación.

4. Run and review / Ejecutar y revisar

Select Execute, complete required checks and record evidence where needed. Pause and resume from the library. Each run keeps its own copy: later edits do not change the instructions followed by an earlier run. Use Activity to review timing and export records as CSV. Reviews and comments are local, not a remote team approval portal.

5. Back up and export / Respaldar y exportar

Use Settings → Your data to locate your actual data folder. The usual path is %APPDATA%\sopbuilder\data\. Create password-protected backups and store a copy separately. Test restoration on a safe copy, because restoring replaces the active workspace after confirmation. Without the password, encrypted backups cannot be recovered. PDF/DOCX/HTML omit internal notes; JSON and packages can include private metadata, comments and attachments.

6. Optional integrations / Integraciones opcionales

AI requires your provider/model configuration and consent per request; no paid usage is included. Local Whisper needs an initial download. Drive needs the developer's production Google OAuth configuration, verification and public consent before it can be advertised as publicly ready. Manual Drive sync is personal, not shared-drive or simultaneous editing support.

7. Troubleshooting and known limits / Ayuda y límites

If activation fails, check the code/email, connection and Windows clock. Too many attempts require a 15-minute wait. An inactive/free Supabase project can interrupt new redemption; a signed local license still works offline. For help send the app version, Windows version and a short description to familiazv2016@gmail.com. Do not send business records or passwords. Scanned PDFs need external OCR; transcription quality must be reviewed; no official macOS/Linux edition or auto-update system is included.
