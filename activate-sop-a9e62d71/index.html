APPSUMO / REDEMPTION

Your code. Your workspace.
Tu código. Tu espacio.

Enter your code and purchase email to receive a signed personal license. No account or password is created; keep your code and license private.

Introduce tu código y correo de compra para recibir una licencia personal firmada. No se crea una cuenta ni contraseña; conserva el código y la licencia en privado.

You're ready / Todo listo

  1. Save the .soplicense file. / Guarda el archivo .soplicense.
  2. Download and install SOPBuilder for Windows. / Descarga e instala SOPBuilder para Windows.
  3. Open the app and choose “Import license”. / Abre la app y elige «Importar licencia».

Windows downloads and SHA-256 checksums ↗

The executable is not Authenticode-signed. / El ejecutable no tiene firma Authenticode.

A code belongs to one personal license and cannot be stacked. Repeat redemption with the same code and email recovers the same license. Email ownership is not verified: the purchase code is your proof of possession.

Un código corresponde a una licencia personal, sin apilado. Canjearlo otra vez con el mismo correo recupera la licencia. No verificamos que el correo te pertenezca: el código es la prueba de posesión.
